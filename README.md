# NZO Store

Catalogue gratuit de plugins pour les apps Craft (EffectCraft…). Tu télécharges, tu ouvres, tu cliques **Installer**.

## Télécharger

Va sur la page **[Releases → dernière version](../../releases/latest)** et prends le fichier de ton ordinateur :

| Ton ordinateur | Fichier |
|---|---|
| Windows | `NZO-Store-Windows.zip` |
| Mac récent (puce M1, M2, M3…) | `NZO-Store-Mac-Apple-Silicon.zip` |
| Mac plus ancien (Intel) | `NZO-Store-Mac-Intel.zip` |

Aucun compte n'est nécessaire.

## Installer en 3 gestes

1. Télécharge le fichier de ton ordinateur et ouvre-le.
2. Windows : double-clic sur `NZO Store.exe`. Mac : glisse `NZO Store` dans Applications.
3. Clique **Installer** sur un plugin, puis relance EffectCraft.

## ⚠️ Mac : l'ouverture peut être bloquée

Je n'ai pas de compte Apple Developer payant, donc l'app n'est pas « signée » et macOS peut dire qu'il ne peut pas vérifier le développeur. Ce n'est pas un virus. Pour l'ouvrir, une seule fois :

1. Clic droit sur **NZO Store** → **Ouvrir** → **Ouvrir** à nouveau, ou
2. **Réglages Système → Confidentialité et sécurité → Ouvrir quand même**.

## Plus d'infos

Les plugins sont vérifiés (somme SHA-256) avant installation. Projet non officiel, par Nozomagarion.
